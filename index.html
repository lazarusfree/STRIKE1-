Site notes

Built to stay simple on Neocities

No framework and no build step. The site stays easy to update by editing plain HTML, CSS, and JavaScript whenever a new repo or note is ready to publish.

The design keeps the original retro shell intact, then adds just enough interaction to make it feel alive: theme memory, live time, clearer navigation, and better project detail.

What I care about

Open source with useful receipts

I want the code to run, the explanation to be honest, and the write-up to be good enough that someone else can learn from the mistakes and the fixes.

  1. Understand the system before polishing the surface
  2. Keep documentation close to the code
  3. Use small projects to build strong fundamentals
  4. Share work in public whenever possible
